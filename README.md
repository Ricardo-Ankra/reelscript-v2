# Reelscript

An AI-orchestrated video studio. A short prompt becomes a brand-consistent,
publish-ready video — the script, scene structure, and visual composition are
generated by AI and rendered programmatically with Remotion, rather than edited
frame by frame.

V1 targets personal use by a single operator running multiple channels, with an
architecture designed to be multi-tenant-capable without a rewrite.

## How it works

A channel holds a complete brand definition (voice, palette, fonts, logos). For
each video, the workflow runs in deliberate phases so expensive steps only happen
after cheaper ones are committed:

1. **Prompt & configuration** — prompt, aspect ratio, length, captions, music.
2. **Script & scenes** — the AI writes a streamed, editable script broken into
   scenes and shots.
3. **Review & iterate** — edit inline, regenerate shots, chat with the prompter.
4. **Voice synthesis** — deliberate, per-scene voiceover via ElevenLabs.
5. **Generation** — the AI composes a render spec from reusable primitives,
   chooses assets, and Remotion Lambda renders it.
6. **Review, music & export** — preview, adjust music, push drafts to social.

The core principle is that the AI emits validated *recipes* (text, JSON), never
raw output; rendering is a deterministic transformation of those recipes.

## Stack

Next.js (App Router) + React + Tailwind on Vercel · Supabase (Postgres + Auth +
Realtime, RLS on) · Cloudflare R2 · Inngest · Remotion Lambda (AWS) ·
Anthropic / OpenAI · ElevenLabs · Pexels / Pixabay.

Only two things are operated directly — the Next.js app and the Inngest
functions; everything else is a managed service.

## Getting started

The build follows `docs/build-plan/` phase by phase. Phase 0 (Foundations)
stands up the app shell, Supabase with the schema applied, auth, RLS, and the
external services (R2, Inngest, AWS). Each phase ends in a demonstrable
milestone; the thin end-to-end slice (prompt → rendered video) is complete at
Phase 4, after which everything is enrichment.

Provisioning you will need before Phase 0's milestone: a Supabase project, a
Cloudflare R2 bucket, an Inngest account, an AWS account for Remotion Lambda,
and API keys for Anthropic and ElevenLabs (Pexels/Pixabay optional).
